## 🧱 Stack

**Frontend**

* React(Uso de hooks personalizados).
* Vite
* JavaScript
* CSS

**Backend**

* Flask (Python)
* SQLAlchemy
* JWT
* Tiempo real con Socket.IO (Websocket)

**Base de Datos**

* PostgreSQL
* Cloudinary
* SendGrid

**Deploy**

* Render
